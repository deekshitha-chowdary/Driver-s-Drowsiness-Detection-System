
# Driver's Drowsiness Detection System

A Python-based computer vision project that monitors eye closure through a webcam and alerts the user when prolonged eye closure is detected.

## Features

- Real-time webcam monitoring
- Face and eye landmark detection using MediaPipe
- Eye closure monitoring using an eye aspect ratio
- Audible warning using the Windows sound system

## Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy

## Installation

1. Clone or download this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   python main.py

Press Q to exit the camera window.

## Disclaimer

This is an educational prototype, not a validated driver-safety system.
